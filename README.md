# EVDS Döviz ve Altın Analizi

## Proje Hakkında
Bu projede EVDS API kullanılarak 2024 yılına ait USD, EUR, CHF ve gram altın verileri elde edilmiştir.

Python ile veri çekme, temizleme, dönüştürme ve finansal analiz işlemleri gerçekleştirilmiştir. Analiz sonucunda elde edilen veriler SQL ortamına aktarılmak üzere hazırlanmıştır.

## Kullanılan Teknolojiler
- Python
- Pandas
- Requests
- Python-dotenv
- EVDS API
- SQL

## Yapılan Analizler
- Günlük getiri istatistikleri
- En yüksek ve en düşük günlük getiriler
- Yıllık toplam değişim
- Aylık döviz ve altın getirileri
- Döviz ve altın performans karşılaştırması
- Korelasyon analizi
- Günlük getiri oynaklığı
- Aylık piyasa hareketliliği
- Yıllık performans karşılaştırması

## Veri Kaynağı
Türkiye Cumhuriyet Merkez Bankası - EVDS

## Veri Çıktısı
Analiz edilen veriler SQL ortamında kullanılmak üzere CSV formatında dışa aktarılmıştır.
